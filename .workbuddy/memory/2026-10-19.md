## 导入链路：新增 ZIP 资料包（多 md + images）支持

- 新增 `utils/zip_utils.py`：安全解压（zip-slip 拦截 / __MACOSX 与隐藏文件过滤 / 符号链接跳过 / 解压总量 2GB、条目 2 万上限）、GBK 文件名修复（无 UTF-8 标记时 cp437 还原后 utf-8→gb18030）、`discover_md_files` 自然序（过滤 `_new.md`）、`MAX_MD_PER_ZIP=50`
- 新增 `utils/md_image_utils.py`：图片引用抽取（Markdown `![]()` + HTML `<img src>` 双语法）、代码块/行内代码区间过滤（避免把文档里的示例语法当真实引用）、相对路径解析（MD 目录 → 资料包根 → 同名递归兜底）、span 倒序替换
- 重写 `node_md_img`：按引用定位图片（不再依赖 `images/` 目录遍历）、同图多引用合并、MinIO 对象名子目录压平为 `__`、URL percent-encoding、上下文各 100 字符供 VL
- `api/file_import_service.py`：`/upload` 支持 `.zip`（≤500MB，流式落盘），一个 zip 内每个 md 生成独立任务（`tasks` 返回 task_id/file_name/source，兼容旧 `task_ids`）；新增可选表单字段 `project_name`（zip 缺省取包名，course_doc 据此 `doc_kind=project`）；`source_file` 记包内相对路径；删除无用的回调式旧实现
- `state.py`：`create_import_default_state` 增加 `project_name` / `source_file` 参数
- `page/import.html`：accept 增加 `.zip`、项目名称输入框、按返回的 tasks 显示任务名
- 新增 `test/test_zip_import.py`：离线自测（解压→发现→引用解析→替换）。实测掌柜智库 19 篇 md + 123 图（57.9MB）→ 123 处引用全部命中，0 死链
- 已知行为：course_doc 无业务主键（uuid），重复上传同一 zip 会产生重复分块（PRD 禁止按文件名批量删，未改）
